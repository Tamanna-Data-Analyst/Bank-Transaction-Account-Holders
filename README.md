# 🏦 Bank Transaction and Account Holders

## 📌 Project Overview
This project analyzes bank transaction data using MySQL and Power BI to explore transaction patterns and generate meaningful business insights.

## 🎯 Problem Statement
The objective of this project is to analyze banking transactions, understand transaction patterns, and identify key business insights to support data-driven decision-making.

## 🛠️ Tools & Technologies
- MySQL
- Microsoft Power BI

## 📂 Project Files

### 1. Database and Tables
`01_database_and_tables.sql`
- Creates the database and required tables.

### 2. Exploratory Data Analysis
`02_exploratory_data_analysis.sql`
- Explores the dataset and examines transaction patterns.

### 3. Business Insights Queries
`03_business_insights_queries.sql`
- Contains SQL queries designed to extract business insights.

### 4. Power BI Dashboard
`Bank Transaction Project.pbix`
- Power BI dashboard for visualizing bank transaction data.

## 🎯 Project Objectives
- Analyze bank transaction data.
- Explore transaction patterns using SQL.
- Extract meaningful business insights.
- Visualize transaction data using Power BI.

## 🏁 Conclusion
This project demonstrates the use of MySQL for data exploration and analysis and Power BI for data visualization and reporting.
